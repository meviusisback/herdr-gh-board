How it works

The tree is the map.

Herdr gives every space, tab and terminal an address. The layout turns that world into a tree you can read, and keeps every colour tied to the state the agent itself reports.

  • 01
    Find the work. A repo folds to its Main checkout, branches and worktrees; each row says its distance from origin and main.
  • 02
    Read the thread. The agent's own store becomes a title, a prompt preview, a model and an effort.
  • 03
    Act in place. Commit, merge, create a repo, start an agent on a branch, open the worktree — the row is the control.
  • 04
    See everything. The wall composes the live terminals of the agents that are working or blocked, or every agent at once.

Install

Clone, copy, switch.

The layout and its mods are plain files in your Herdr home. No package manager, no build, nothing minified: what you read is what runs.

Herdr 0.1.16+gitghhcsqlite3Linux · macOS · Windows

install.sh
# the layout and its 17 mods
gh repo clone meviusisback/herdr-gh-board
cd herdr-gh-board
cp -r layouts ~/.config/herdr-app/
cp -r mods ~/.config/herdr-app/

# merge keys.json, then show the layout
herdr-app do layout.switch \
  '{"name":"repos-and-agents"}'
