# Model marks

The provider glyphs in this folder come from [LobeHub's icon set](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg`, MIT). Each is a one-colour glyph drawn with `currentColor`, so the
card tints it white inside a tile of the provider's own colour.

Taken from `https://unpkg.com/@lobehub/icons-static-svg@1.102.0/icons/<name>.svg`:

`anthropic`, `cohere`, `deepseek`, `gemini`, `meta`, `minimax`, `mistral`, `moonshot`, `nvidia`,
`openai`, `qwen`, `xai`, `zhipu`.
